# Student Management System (C++)

A simple console-based Student Management System developed using C++. This project allows users to manage student records through a menu-driven interface.

### Features
- Add student records
- Display all student records
- Search students by roll number
- Update student information
- Delete individual or all records
- Exit the application

### Technologies Used
- C++
- Standard Input/Output (`iostream`)
- Arrays and Strings
- Functions and Switch Statements
